# 입력 분야 (수정 후 /evaluate-startup 실행)

1. 금융: AI 펀드매니저 (주식 투자 → 더 똑똑해질 필요)
2. 뷰티·헬스케어
   - "자산이 쌓이는 사업" 방향 (아이템 미정 → 팀이 구체화)
   - 화장품·의류에서 나에게 맞는 제품을 찾아주는 AI
   - 복용 시 간·신장 기능을 판단해 맞춤형 건기식을 판매하는 앱
3. 로컬: 인스타그램 핫플을 카테고리별 지도로 정리
4. 농업: 농업 경쟁력 강화, 대규모 농업·농지 집적
5. 글로벌 마케팅
   - 해외 진출·마케팅이 필요한 수출기업용 앱
   - 롱폼 → 다국어 숏폼 변환 앱
   - 해외 인플루언서와 기업/국내 관광스팟(약국, 프랜차이즈) 연결 플랫폼
6. 교육·정신건강
   - 아이 교육 올바른 방향 솔루션 커뮤니티
   - 영유아·청소년 정신건강 위험도 상담 도구 AI
   - 시니어 AI 교육
   - 작곡 AI 사용 가이드 교육
7. 안전: 여성 안전용품(자동 신고·녹음) / 경찰 리뷰 사이트
8. 콘텐츠: AI가 기획·편집·업로드까지 대신하는 쇼츠 자동화 플랫폼

규칙: 사업성이 낮으면 같은 분야 내 다른 아이템으로 대체 발굴 가능.
