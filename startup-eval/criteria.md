# 평가 기준 (공통 참조 문서)

## 필수 조건 (하드 필터) — 하나라도 불충족 시 탈락, 같은 분야의 대안 아이템으로 전환
1. 초기 투자금 5천만 원 미만으로 MVP 출시 가능
2. 5~10년 내 기업가치 500억 원 이상에 도달할 수 있는 현실적 경로 존재
(자금 조달 방식은 제한 없음: 외부 투자·정부지원·자체 매출 모두 허용)

## 점수 가중치 (v2, 100점) — 팀 구성은 startup-eval/team-profile.md 참조
| 항목 | 배점 |
|---|---|
| 경쟁 환경·방어력 (경쟁사 조사 기반, 최우선) | 25 |
| 시장 규모·성장성 | 20 |
| 500억 도달 경로 | 15 |
| 팀 적합도 (개발자 강점 활용 / 약사 자격 활용 / 영업·도메인 공백 위험) | 15 |
| 5천만 원 내 MVP 가능성 | 10 |
| 실행 난이도 (낮을수록 고득점) | 10 |
| 규제·법적 리스크 (낮을수록 고득점) | 5 |

※ v1(2026-11-16 실행분)은 시장 25/경로 20/방어력 20/MVP 15/규제 10/난이도 10이며 팀 적합도 항목이 없었다. v1과 v2 점수는 직접 비교하지 말 것.
※ 경쟁 환경 25점은 "이미 존재하는 서비스 대비 우리가 이길 구체적 이유"를 제시하지 못하면 최대 10점으로 제한한다.

## 판정 기준
- 80점 이상: Go / 65~79: 조건부 Go(보완 조건 명시) / 65 미만: No-Go
- 레드팀이 치명적 결함(Critical)을 제기하면 점수와 무관하게 조건부 Go 이하로 강등

## 근거 규칙
- 수치(시장규모, 경쟁사 현황, 법규)는 웹 검색으로 확인하고 출처 URL 병기
- 확인 못 한 것은 "확인 불가"로 표기, 추정은 "추정"으로 명시하고 가정을 적는다
