# 인스타 핫플 서비스 심층 분석 노트 (L1 재정의) — 2026-11-17

※ 대화에서 나온 내용을 저장한 것. 소크라테스 방식 논의의 중간 기록. 결론 아님.
※ 사용자 메모 링크(notes.doctorcall.cloud)는 세션 네트워크 허용 목록 밖이라 열지 못함. 아래는 대화에 붙여 넣은 텍스트 기준.

## 1. 사용자 원래 아이디어 (메모)
- 인스타그램에서 핫한 장소를 지도 형태로 정리. 인스타 활동을 지도로 옮겨주고 추천까지. 카테고리별 정리. (식당 광고와 연결)
- 사용자 지적: 트래픽이 생겨야 수익이 남(그걸 본 사람들이 그 장소를 가야 함). 투명성: 실제 핫한 장소의 신뢰성 vs 광고비 받아야 함의 충돌
- 누적 평점·저장형 지도는 네이버지도가 이미 있음 → 차별점은 "진짜 트렌딩": 지금 인스타에서 핫한 곳, 이제 막 성수에서 뜨기 시작한 곳
- 프로토타입 계획: 성수·연남 식당 30~50곳의 최근 게시물 반응을 반자동으로 수집해 2주 안에 프로토타입

## 2. 이전 평가 요약 (L1)
- 이전 점수: 하드필터 탈락(500억 경로 불충족). 사유: HOTPLE(REGO) 동일 컨셉, 네이버·카카오·캐치테이블이 팝업·핫플 기능 흡수, 광고 의존 ARPU 낮음
- HOTPLE: SNS 게시글 공유 → AI가 장소 분석해 지도 저장, 기간 한정 장소 알림. 투자·사용자 수 확인 불가
- 네이버: 2025-06 팝업 정보 노출, 팝가(스위트스팟) 제휴 2025-07, 지도 예약 탭 2025-11

## 3. 재정의: "초기 급상승 감지 (early trending)"
- 누적형 지도와 겹치지 않는 영역이나, 구조적 긴장 있음: 신호를 공개하는 순간 초기 발견 가치가 줄어듦 → 예측 적중률이 곧 가치
- 프로토타입이 검증할 가설(제안)
  1. 인스타 반응 급증이 몇 주 뒤 실제 방문(네이버 리뷰 증가·캐치테이블 웨이팅)을 선행하는가
  2. 사용자가 목록을 보고 실제로 가는가(클릭·저장·방문 인증, 지인 20~30명 주 1회 발송)
  3. 협찬 게시물을 제외하면 적중률이 오르는가
- 미결: 프로토타입에서 "맞았다"를 무엇으로 판정할지(사용자가 아직 답하지 않음)

## 6. 비즈니스 모델 논의 진행 상황 (소크라테스 Q&A 기록)
1. Q. 누가 돈을 낼 것인가? (식당 / 소비자 / 데이터 구매 제3자)
   A. **식당(광고주)과 제3자(데이터 구매자)**. 1은 소비자 트래픽 필요, 3은 트래픽 없이 시작 가능(팝업 기획사·브랜드·상권 업체가 급상승 신호 구매, 이전 L2 아이디어와 연결)
2. Q. 식당이 사는 것은 노출인가 자기 가게 반응 리포트인가?
   A. **노출을 높이는 것**
3. Q. 광고가 섞여도 사용자가 목록을 믿으려면 무슨 조건이 필요한가?
   A. 사용자의 설계: **사용자가 자기 저장 장소 외에 뜨는 곳 추천을 요청할 때, 광고하는 업장도 같이 상단 노출**
4. Q. 광고비를 낸 업장이 실제로 안 뜨는 곳이어도 상단에 올려도 되나?
   A. **트렌드 기준이 필요함**(광고주도 최소 트렌드 기준 충족해야)

## 7. 열린 질문 (다음에 이어갈 것)
- **광고 모순:** 기준을 넘은 업장은 이미 뜨고 있어 광고 필요성이 약하고, 광고가 가장 절실한 곳은 기준 미달이라 광고 불가. 광고를 내는 업장은 어떤 곳이어야 하나? 후보
  - 이미 뜨는 곳이 흐름을 더 키우려는 광고
  - 막 뜨기 시작한 곳(기준 직전)이 한 단계 올라가려는 광고
  - 신규 오픈 등 별도 조건으로 기준 면제
  - 식당 입장에서 "내가 왜 광고비를 내야 하나"를 한 문장으로?
- 제3자 데이터 판매(B2B)를 어느 시점에 어떻게 붙일지(트래픽 없는 초기 수익원 후보)
- 프로토타입의 적중 판정 기준
- 트래픽 확보 전 초기 수익/비용 구조
