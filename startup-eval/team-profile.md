# 창업팀 프로필 & 설계 함의 (v2)

## 팀 구성 (2인)
| 구성원 | 보유 역량 | 없는 것(공백) |
|---|---|---|
| A. 컴퓨터과학 출신 개발자 | 시스템 최적화, ML, 에이전트 구축 | B2B 영업, 업계 인맥, 콘텐츠·브랜드 감각 |
| B. 약사 + 기획/마케팅 | 약학 전문성, 식품 커머스 1회 운영 경험, 기획·마케팅 | 수출·무역 실무, 음악 산업, 아동발달/교육 임상, 규모 있는 광고 운영 |

## 팀 특성 종합 (강점 → 설계 방향)
1. **소수 인원으로 AI 네이티브 제품을 만들 수 있다** → 인건비 구조가 가벼워 "5천만 원 MVP" 조건에 유리. 사람 손이 많이 드는 서비스업(대행·유통·인력)은 팀 강점을 못 쓰므로 감점.
2. **시스템 최적화 + 에이전트 경험** → 크롤링·파이프라인·비용 최적화가 필요한 데이터/자동화 제품에 강점. 반대로 *플랫폼 데이터 접근이 막힌* 아이템은 기술로 못 푼다(법·약관 문제).
3. **약사 자격** → 건기식·화장품·의료 인접 영역의 규제 해석과 신뢰(전문가 브랜드), 그러나 *자격 자체가 영업 해자가 되려면 소비자 대면 도메인*이어야 한다. 수출·음악·숏폼 영역에서는 직접 해자가 아님.
4. **식품 커머스 1회 경험** → 커머스 구조(소싱·MD·CS·광고) 이해는 있음. 다만 *성공 이력 여부와 규모는 확인되지 않았고*, 1회라 반복 검증된 역량은 아님.
5. **공백: 영업·도메인 네트워크** → B2B(수출기업, 음악 산업)는 개발자 2인이 *영업 채널 없이* 파는 구조가 되어 위험. Product-led(셀프서브 구독)·마켓플레이스·콘텐츠 유입형이 적합.

## 설계 원칙 (에이전트 팀에 반영)
- **경쟁사 조사 최우선**: 평가 배점 25점으로 최대. 국내·해외 직접/간접/대체재 + 빅테크 진입 가능성 + 가격/투자/트래픽 실측 + "이미 존재하는데 왜 우리가 이기나"를 반드시 답한다.
- **팀 적합도(15점)를 신설**: 개발자 강점 활용도, 약사 자격 활용도, 공백(영업·도메인) 위험.
- **판정은 보수적**: 기존 65점 미만 No-Go 유지, 레드팀 Critical은 강등.
- **같은 산업 내 대체 아이템 발굴**: 원안이 낮으면 팀 적합도 높은 방향으로 변형.
