# E1·E2 규제·법적 리스크 (regulation-feasibility 보고 요약) — 법률 자문 아님, 변호사·관세사 검토 필요
검색 14회 중 2회 오류 후 재검색.
## E2 (규제 적합성 SaaS + 대행)
- 점검 결과 오류 책임 High(면책은 고의·중과실까지 못 막음 — 추정; 참고용 문구·책임한도·전문가 검수 옵션·배상책임보험)
- 관세사법 Mid: 타인 의뢰 통관업(수출입 신고 대행·상담)은 관세사·관세법인·통관취급법인만 가능 → SaaS 점검만은 침범 가능성 낮음, 신고서 작성·제출 대행은 관세사 제휴 필요(조문 번호·벌칙 확인 불가) https://ko.wikisource.org/wiki/%EA%B4%80%EC%84%B8%EC%82%AC%EB%B2%95
- 행정사법 Mid: 행정기관 제출 서류 작성·제출 대행 업으로 하면 처벌 대상, 미국 FDA·EU CPNP 등 외국 기관 제출에도 적용되는지 쟁점(확인 필요). 변리사법 확인 불가(상표 출원 대행 제외 권장)
- 외국 법령 자문 소지 Mid → "정보 제공이며 법률 자문 아님" 고지, 현지 대리인 제휴. MoCRA 미국 대리인은 미국 내 소재 필요 → 직접 수행 불가·제휴 필요 https://www.fda.gov/cosmetics/registration-listing-cosmetic-product-facilities-and-products
- 규제 DB: 공공누리 제1유형 상업 이용 가능, 제2·4유형 불가; 민간 가공 DB 크롤링은 약관 위반 위험 Low~Mid
- 농식품부 글로벌 식품 규제 자동화 플랫폼(20개국+, AI 자동 준수 확인, 2026 오픈 목표) 보도 https://www.mafra.go.kr/bbs/home/793/582237/artclView.do — 2차 기사 기반 재확인 필요
- 점수: 규제 위험 3.5/5(SaaS만 3.0, 대행 병행 4.0) → criteria 득점 1.5/5, 실행 난이도 7/10
## E1 (바이어 발굴·이메일 아웃리치)
- 데이터 공급사 약관·스크레이핑 High: LinkedIn 약관이 스크레이핑 금지, 2025 Apollo·Seamless 페이지 삭제 https://www.leadgenius.com/resources/linkedins-crackdown-on-data-scrapers-why-apollo-io-and-seamless-ai-were-targeted--and-whos-next → 라이선스 DB 사용(재판매 허용 확인)
- EU 수신자 High: GDPR 정당한 이익+균형성 테스트 문서화, ePrivacy 국가별 상이(독일 B2B도 사실상 동의) → 초기엔 영국·미국·동남아 중심
- 미국 CAN-SPAM Low~Mid(FTC 원문 확인 필요), 한국 정보통신망법 제50조 Low(해외 수신자 적용 여부 확인 불가), 개인정보보호법 Mid(역외적용 명문 규정 없음, 국외이전 검토)
- 수출바우처: 수행기관·특수관계 기업은 참여기업(수혜자) 제외, 수행기관 등록 요건(자본금·실적·심사 기간) 확인 불가
- 점수: 규제 위험 3.5/5(지역 제한 시 2.5) → 득점 1.5/5, 실행 난이도 4/10
## 사전 조치 3가지: ① 변호사 검토(관세사법·행정사법·변리사법 경계, 면책·책임한도, 국외이전), 서비스는 '정보 제공+체크리스트', 신고·등록은 관세사·현지 대리인·행정사 제휴 ② 데이터 출처 감사(E1 연락처 수집 경위·재판매, 대상 지역 제한, 수신거부·균형성 테스트; E2 DB별 공공누리 유형·출처·시점·검수자 기록) ③ 수행기관 요건·공공 플랫폼 범위 확인, 고객 3~5곳 지불의사 검증
