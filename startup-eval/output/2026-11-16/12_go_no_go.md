# Go / No-Go 판단 (2026-11-16)
**최종 결정은 창업자가 내립니다.** 이 문서는 에이전트 추정과 웹 검색 요약에 기반한 참고 자료이며, 투자·법률·임상 판단이 아닙니다.

**Go 또는 조건부 Go 후보는 없습니다.**

## 해석
1. 이번 후보군에서는 "5천만 원 미만으로 시작해 5~10년 내 기업가치 500억"을 현실적으로 보여주는 아이템이 없었다. 대부분 낙관 시나리오(고객 수·배수 모두 높게)에서만 500억에 닿는다
2. 높은 점수일수록 해외 확장 또는 B2B 대형 채널이 필요하다(G1, G4, F2, E5). 국내 SaaS 단독은 SOM이 50~200억에 머문다
3. 낮은 점수의 주 원인은 "대형 플랫폼·선두의 무료 제공"(F1, L2, C2, E5)과 규제 책임(F2, A2, G4, E5)이다

## 추천 순위와 다음 단계 (결정은 창업자)
"지금 시작"이 아니라 **싸게 검증한 뒤 재평가**하는 순서를 권한다. 목표(500억)와 현실(5천만 원) 사이 간극이 크므로, 2~4주의 저비용 검증으로 핵심 가정 하나씩을 확인한다.

### 1순위 후보: S3 (유일하게 치명적 결함 없음)
첫 4주 검증:
1. 주차 1: 대상 사업장 수 파악(KOSIS 사업체 규모별 집계), 고용노동부 신 지침 원문·과태료 시행일 확인
2. 주차 2~3: 5~50인 제조·건설·물류 사업장 안전 담당자·행정사 인터뷰 15명 이상, 현재 어떻게 서류를 만드는지·얼마를 지불하는지
3. 주차 3~4: 무료 대체재(KOSHA, 엑셀 양식) 대비 차별점을 보여주는 프로토타입(서류 1종) 시연, 유료 선결제 의향 3곳 이상
4. 통과 기준: 유료 의향 3곳 이상, 월 5만 원 이상 지불 확인. 미달이면 중단

### 2순위: G4 (약사 전문성이 의미 있게 쓰일 수 있는 유일한 후보군)
1. 화장품·건기식 해외 판매 K-브랜드 대행사·SME 10곳 인터뷰: 광고 규제 때문에 소재가 반려되거나 계정이 정지된 경험·비용
2. 1개국(예: 미국)·1개 카테고리(화장품) 규제 체크리스트를 수동으로 만들어 유료 파일럿 3곳에 제공(소프트웨어 없이)
3. 통과 기준: 건당 또는 월 정액 지불 의향, 오류 책임을 "참고용" 표기로도 구매하는지
4. 책임 구조(면책·보험)는 변호사 확인 전에 상용화 금지

### 3순위: G1 (해외 확장 모델이 입증되면 재평가)
수출바우처 수행기관 등록 요건과 구하다 가격 확인, 일본·동남아 1개국 고객 확보 경로 분석이 먼저.

### 중단 권고
F1, B1, A2, F2, E5, L2, C2: 현재 정보로는 추진 근거 부족. 단 **B1과 B3(약국 SaaS)는 약사인 창업자에게 직접 연결되는 아이템**이므로, 점수와 별개로 "약사 단독 역량으로 구독 경로·약국 네트워크를 확보할 수 있는지"를 따로 판단해 볼 가치가 있다(에이전트는 약사 전문성을 점수에 넣지 않음).

## 확인되지 않은 항목 (결정 전 확인 필요)
- S3: 대상 사업장 수, 유료 지불 단가, 신 지침·과태료 시행일 원문
- G4: 직접 경쟁자(Veriad 등), 지불의사, 규제 DB 비용
- G1: 바우처 수행기관 요건, 구하다 가격
- L2: 오픈업 현재 상태(무료 공개 vs 폐업 표기 불일치)
- F2: 퇴직연금 RA 실가입 금액 시점
- B1: 온라인 소분·택배 판매 허용 여부(식약처 질의회신), 약사 법적 역할(약사법 원문)
- 공통: 배수·단가·고객 수 가정은 모두 추정, 에이전트별 검색이 얕음

## 팀 개선 제안 (다음 실행 전)
1. 하드필터 단계에서도 웹 검색을 필수로 할 것(이번엔 가정만 사용해 3단계 결과와 모순 발생)
2. 가중치 재검토: 500억 도달을 20점 항목으로만 두면 모든 후보가 낮게 나오므로, 필터 기준과 점수 기준을 일관되게 정의
3. 약사 전문성 활용도를 별도 참고 항목으로 병기
4. 에이전트들이 후보 원문을 읽지 못하는 경우를 막도록 입력 파일을 프롬프트에 포함
