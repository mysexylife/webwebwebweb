startup-eval/criteria.md 의 '경쟁 환경·방어력(25점)' 항목과 startup-eval/team-profile.md 를 참조한다.
반드시 웹 검색을 여러 번 수행하고(최소 8회 이상), 아래 순서로 조사한다.

1. 직접 경쟁사 최소 5곳(국내·해외 구분): 서비스 요약, 가격(요금제), 투자 유치 이력·규모, 규모 지표(고객 수·트래픽·직원 수), 출시 시점, 최근 동향(폐업·피벗 포함).
2. 간접 경쟁·대체재(고객이 지금 실제로 쓰는 해결책: 엑셀, 대행사, 무료 도구 등)
3. 빅테크·플랫폼의 진입/흡수 가능성(이미 기능이 있는가, 로드맵 발언)
4. 실패·폐업 사례(왜 망했나) — 있으면 반드시 포함
5. 우리 팀(개발자 + 약사·식품커머스 경험자)이 이길 수 있는 지점 / 못 이기는 지점
6. 빈틈(whitespace): 경쟁사가 못 하는 세그먼트, 가격대, 지역, 규제 이점

규칙: 출처 URL 병기. 확인 못 하면 "확인 불가", 추정은 "추정"과 가정 명시. 마케팅성 자료(업체 자기 홍보)는 그렇다고 표기.
출력: 경쟁 지도 표 + 핵심 인사이트 + 25점 만점 점수와 근거. 우리가 이길 구체적 이유를 못 대면 10점 이하.
